# Proyecto-Alpha_Logic
Descripción general:

Luna App es una aplicación móvil desarrollada para permitir a las mujeres nicaragüenses llevar registro de sus ciclos menstruales, embarazos y etapa de menopausia. El objetivo principal que tenemos es darle a las usuarias una herramienta personalizada y familiar en la que registrar sus datos de las especificaciones anteriormente mencionadas, y poder realizar predicciones y cálculos, todo esto guardando la información de manera puramente local. (en sus dispositivos, utilizando la herramienta shared_preferences)

Por lo pronto, en la aplicación habrá acceso a idioma español, inglés y miskito, para garantizar un nivel de accesibilidad alto para las mujeres del país.

Tecnologías en uso:

Estamos en proceso de integración de bases de datos en Firebase, más específicamente Cloud Firestore. Esto hará posible el registro y autenticación de las usuarias de forma segura, así como también la adición de artículos científicos comprobados que se adapten a las necesidades de las usuarias.

Instalación:

El proyecto está actualmente y de manera aproximada en 30% de su desarrollo para la fase de exposición. Nos estamos enfocando en la construcción de la interfaz (frontend) y el funcionamiento fundamental de la aplicación (backend)
